# Pixel Studio 0.2.1

В версии 0.2.1: масштабирование выбранного слоя и рамка Ctrl+T, исправленный поворот и заливка с допуском, обновление через GitHub после закрытия редактора, вход Google на любом ПК. GIF и обычные картинки можно редактировать вместе.

[Скачать Pixel Studio 0.2.1 для Windows x64](https://github.com/Over1inex/pixel-studio/releases/download/v0.2.1/Pixel-Studio-0.2.1-Windows.zip) · [Последний релиз](https://github.com/Over1inex/pixel-studio/releases/latest)

В Windows-архиве находятся `Pixel Studio.exe` и `Удалить Pixel Studio.exe`. Исходники версии 0.2.1 находятся в этом репозитории; самостоятельная сборка описана в [CONTRIBUTING.md](CONTRIBUTING.md).

Самостоятельное Windows-приложение для редактирования изображений. **Запуск: дважды нажмите `Pixel Studio.exe`.** Node.js и локальный сервер для работы не нужны. Интерфейс встроен в EXE и открывается в отдельном окне через системный Microsoft WebView2 Runtime. Сайт редактора открывать не требуется.

Для удаления закройте редактор и запустите **«Удалить Pixel Studio.exe»** рядом с EXE приложения. Окно удаления позволяет также убрать настройки, кеш, профиль и данные входа текущего пользователя Windows. Программа удаляет собственные EXE и ярлык; сохранённые изображения, файлы проектов, исходники и облачные проекты сохраняются. Права администратора не нужны. До нажатия «Удалить программу» ничего не удаляется.

## Работа без интернета

- Создание холста и импорт PNG, JPEG и WebP с компьютера.
- Кисть, ластик, заливка слоя, пипетка, текст, прямоугольники и эллипсы.
- Слои: создание, дублирование, порядок, видимость, прозрачность и переименование.
- Отмена и повтор действий, фильтры, поворот и отражение.
- Экспорт PNG/JPEG и сохранение проекта со слоями в `.pixel.json`.
- GIF: импорт до 120 кадров и 60 секунд, воспроизведение/пауза (Space), наложение обычных изображений и текста, экспорт GIF с сохранением анимации. PNG/JPEG сохраняют выбранный кадр.
- «Слой → Размер выбранного слоя» меняет только выбранную картинку. Ctrl+T включает рамку с угловыми маркерами; Enter применяет, Esc отменяет. Пропорции по умолчанию сохраняются, Shift временно меняет режим. Другие слои и размер документа остаются прежними.
- Кнопки «Поворот» и «Отразить» действуют на выбранный слой вокруг его центра. «Изображение → Размер всего изображения» отдельно масштабирует документ целиком. Ctrl+Z отменяет операцию.
- Заливка: допуск 0–255 (по умолчанию 32), смежные пиксели и непрозрачность. Точное совпадение доступно при допуске 0.

Текст после размещения становится растровым. PSD, CMYK, плагины Adobe и генеративный ИИ не поддерживаются. Pixel Studio — самостоятельный редактор с базовыми функциями.

## Google-вход и облачные проекты

Интернет нужен для входа и облачного хранения. Нажмите **«Войти → Войти через Google»**. Авторизация откроется в системном браузере; после входа вернитесь в приложение. Холст останется открытым. Приложение не получает ваш пароль Google.

Статус облака в верхней панели открывает окно аккаунта. Кнопка «Проверить подключение» показывает ход и время проверки. При сбое причина остаётся в окне: ошибка DNS, защищённого соединения, таймаут, ответ сервера или отсутствие служебного доступа. Чтение повторяется при временном сбое; сохранение автоматически повторно не отправляется, чтобы не создавать дубли. После восстановления интернета приложение проверяет облако снова. Сохранённый аккаунт не сбрасывается из-за временной потери связи.

Диагностика Windows-клиента: `%LOCALAPPDATA%\PixelStudio\connection.log`. Журнал ограничен по размеру; содержит время, тип операции, обобщённый маршрут, HTTP-статус и код результата. Пароли, токены, адреса проектов и содержимое файлов не записываются. Если ошибка повторится, код из «Подробности подключения» поможет определить причину. Плавающий сбой предыдущей версии при проверке не воспроизвёлся; сообщения об ошибках теперь различают его возможные источники.

Cloudflare обслуживает доступный из интернета API: D1 хранит метаданные, R2 — файлы проектов. Интерфейс редактора с сервера не загружается. Сервер проверяет владельца при каждом обращении к проекту. Каждый Google-пользователь получает отдельное пространство проектов. Публичный адрес API не даёт анонимного доступа к проектам.

Отдельный служебный ключ на новом ПК больше не нужен. Пароль вводится на странице Google в системном браузере. Запрашиваются только openid, email и profile; доступ к Gmail, Drive или управлению Google-аккаунтом не запрашивается. Сервер проверяет подпись, audience, issuer, nonce и срок Google-токена. Собственные сеансы редактора хранятся в D1 в виде хешей; на ПК cookie шифруется Windows DPAPI. Чужой проект нельзя прочитать, перезаписать или удалить даже по известному ID. См. [обработку данных](PRIVACY.md).

## Обновления

Версия 0.2.1 автоматически проверяет новые выпуски Over1inex/pixel-studio при запуске и раз в 6 часов. Новая версия появится в верхней панели и в «Обновления». По кнопке «Скачать и установить после закрытия» архив загружается с GitHub и проверяется по SHA-256 из метаданных релиза, разрешённому адресу, составу архива и версиям EXE. Ключи облака и Google-сеанс не передаются GitHub.

Продолжайте редактирование и сохраните проекты. Обновление устанавливается после закрытия всех окон этой копии редактора; следующее открытие запускает новую версию. Файлы проектов и данные входа не заменяются. Предыдущие файлы сохраняются с суффиксом .previous; при ошибке выполняется откат. Если восстановить файл не удалось, установщик сообщает об этом и сохраняет резервную копию. Установку можно отложить до закрытия через окно «Обновления».

Версия 0.2.0 не содержит этого механизма — один раз скачайте 0.2.1 вручную. Для обычного запуска сначала распакуйте архив в свою папку, затем запускайте EXE. Исправлено удаление из временной папки WinRAR: занятая пустая папка не считается ошибкой удаления программы.

## Управление

| Действие | Клавиши |
|---|---|
| Кисть / ластик / перемещение | B / E / V |
| Прямоугольник / эллипс / текст | R / O / T |
| Пипетка / заливка | I / G |
| Отмена / повтор | Ctrl+Z / Ctrl+Shift+Z |
| Сохранить проект на ПК / в облаке | Ctrl+S / Ctrl+Shift+S |
| Открыть проект / новый проект | Ctrl+O / Ctrl+N |
| Показать / скрыть боковые панели | Tab |
| Воспроизведение / пауза GIF | Space |
| Трансформировать выбранный слой | Ctrl+T, Enter / Esc |
| Вписать холст | 0 |

Заливка меняет область похожего цвета на выбранном слое. Снятие «Смежные пиксели» выбирает похожие пиксели во всём слое. Изображения добавляются отдельным слоем. Для продолжения работы сохраняйте `.pixel.json` или облачный проект: PNG/JPEG объединяют видимые слои. История отмены хранится только в текущем сеансе.

Файлы проектов открываются через **«Мои проекты → Открыть файл»**. Сохранение на ПК доступно в окне экспорта и в окне аккаунта; оно работает без входа.
