# Pixel Studio 0.2.0

В версии 0.2.0: светлая/тёмная тема («Вид → Панели и оформление»), меню редактора, изменение размера («Изображение → Размер изображения»), анимированные GIF и обычные изображения в одном проекте. Исправлены читаемость полей и ползунков в светлой теме, проверка подключения и сообщения о сбоях облака.

Исходники версии 0.2.0 находятся в этом репозитории. Сборка EXE описана в [CONTRIBUTING.md](CONTRIBUTING.md). [Ранее опубликованные сборки](https://github.com/Over1inex/pixel-studio/releases) могут иметь другой номер версии.

Самостоятельное Windows-приложение для редактирования изображений. **Запуск: дважды нажмите `Pixel Studio.exe`.** Node.js и локальный сервер для работы не нужны. Интерфейс встроен в EXE и открывается в отдельном окне через системный Microsoft WebView2 Runtime. Сайт редактора открывать не требуется.

Для удаления закройте редактор и запустите **«Удалить Pixel Studio.exe»** рядом с EXE приложения. Окно удаления позволяет также убрать настройки, кеш, профиль и данные входа текущего пользователя Windows. Программа удаляет собственные EXE и ярлык; сохранённые изображения, файлы проектов, исходники и облачные проекты сохраняются. Права администратора не нужны. До нажатия «Удалить программу» ничего не удаляется.

## Работа без интернета

- Создание холста и импорт PNG, JPEG и WebP с компьютера.
- Кисть, ластик, заливка слоя, пипетка, текст, прямоугольники и эллипсы.
- Слои: создание, дублирование, порядок, видимость, прозрачность и переименование.
- Отмена и повтор действий, фильтры, поворот и отражение.
- Экспорт PNG/JPEG и сохранение проекта со слоями в `.pixel.json`.
- GIF: импорт до 120 кадров и 60 секунд, воспроизведение/пауза (Space), наложение обычных изображений и текста, экспорт GIF с сохранением анимации. PNG/JPEG сохраняют выбранный кадр.
- Изменение размера всех слоёв с сохранением пропорций, плавным масштабированием или чёткими пикселями; Ctrl+Z отменяет изменение.

Текст после размещения становится растровым. PSD, CMYK, плагины Adobe и генеративный ИИ не поддерживаются. Pixel Studio — самостоятельный редактор с базовыми функциями.

## Google-вход и облачные проекты

Интернет нужен для входа и облачного хранения. Нажмите **«Войти → Войти через Google»**. Авторизация откроется в системном браузере; после входа вернитесь в приложение. Холст останется открытым. Приложение не получает ваш пароль Google.

Статус облака в верхней панели открывает окно аккаунта. Кнопка «Проверить подключение» показывает ход и время проверки. При сбое причина остаётся в окне: ошибка DNS, защищённого соединения, таймаут, ответ сервера или отсутствие служебного доступа. Чтение повторяется при временном сбое; сохранение автоматически повторно не отправляется, чтобы не создавать дубли. После восстановления интернета приложение проверяет облако снова. Сохранённый аккаунт не сбрасывается из-за временной потери связи.

Диагностика Windows-клиента: `%LOCALAPPDATA%\PixelStudio\connection.log`. Журнал ограничен по размеру; содержит время, тип операции, обобщённый маршрут, HTTP-статус и код результата. Пароли, токены, адреса проектов и содержимое файлов не записываются. Если ошибка повторится, код из «Подробности подключения» поможет определить причину. Плавающий сбой предыдущей версии при проверке не воспроизвёлся; сообщения об ошибках теперь различают его возможные источники.

Cloudflare обслуживает закрытый API: D1 хранит метаданные, R2 — файлы проектов. Интерфейс редактора с сервера не загружается. Сервер проверяет владельца при каждом обращении к проекту. В текущей конфигурации разрешён только Google-аккаунт владельца приложения.

Для этого ПК отдельно настроен доступ к закрытому сервису. Служебный ключ не включён в EXE, исходники или архив приложения. Он хранится в `%LOCALAPPDATA%\PixelStudio\service-access.bin`, зашифрованный Windows DPAPI для текущего пользователя. Сеанс аккаунта также защищён средствами Windows; выход отзывает его на сервере.

Копирование EXE на другой ПК сохраняет возможность работать с локальными файлами. Чтобы подключить облако на новом ПК или под другим пользователем Windows, владелец сервиса должен отдельно настроить служебный доступ. Порядок описан в [GOOGLE-SETUP.md](GOOGLE-SETUP.md).

## Управление

| Действие | Клавиши |
|---|---|
| Кисть / ластик / перемещение | B / E / V |
| Прямоугольник / эллипс / текст | R / O / T |
| Пипетка / заливка | I / G |
| Отмена / повтор | Ctrl+Z / Ctrl+Shift+Z |
| Сохранить проект на ПК / в облаке | Ctrl+S / Ctrl+Shift+S |
| Открыть проект / новый проект | Ctrl+O / Ctrl+N |
| Показать / скрыть боковые панели | Tab |
| Воспроизведение / пауза GIF | Space |
| Вписать холст | 0 |

Заливка окрашивает весь выбранный слой. Изображения добавляются отдельным слоем. Для продолжения работы сохраняйте `.pixel.json` или облачный проект: PNG/JPEG объединяют видимые слои. История отмены хранится только в текущем сеансе.

Файлы проектов открываются через **«Мои проекты → Открыть файл»**. Сохранение на ПК доступно в окне экспорта и в окне аккаунта; оно работает без входа.
