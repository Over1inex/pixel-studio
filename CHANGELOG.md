# Изменения

## 0.2.1

- «Размер выбранного слоя» масштабирует только выбранную картинку; холст и остальные слои сохраняются. Для всего документа оставлена отдельная команда.
- Ctrl+T: рамка слоя, угловые маркеры, перемещение, пропорции, Enter и Esc. Один сеанс трансформирования отменяется одним Ctrl+Z; GIF сохраняет кадры и задержки.
- Кнопки поворота и отражения работают вокруг центра выбранного слоя. Исправлено сохранение повёрнутого контекста после поворота холста, вызывавшее фрагменты при следующем переносе.
- Заливка получила допуск цвета 0–255, смежные пиксели и непрозрачность. Обход не зацикливается при близком цвете замены.
- Горячие клавиши учитывают физические клавиши и работают в русской раскладке.
- Проверка новых GitHub-релизов, уведомление, скачивание по кнопке и установка после закрытия. Проверяются адрес, SHA-256, файлы архива и версии EXE; выполняется откат при ошибке установки.
- Исправлено удаление из временной папки WinRAR: вспомогательный процесс работает вне папки приложения; удерживаемая пустая папка не считается ошибкой удаления.
- Google-вход на разных ПК без отдельного служебного ключа. По решению владельца API доступен из интернета, а каждый Google-пользователь получает свои приватные проекты. Добавлен тест production Worker с двумя изолированными аккаунтами.

## 0.2.0

- Меню «Файл», «Правка», «Изображение», «Слой», «Вид»; названия инструментов и горячие клавиши.
- Работающая кнопка «Панели», светлая/тёмная тема, показ и скрытие боковой панели.
- Читаемые числовые поля, светлые полосы прокрутки, ползунки и кнопки в светлой теме.
- Изменение размера всех слоёв с сохранением пропорций, выбором масштабирования и отменой.
- Анимированные GIF вместе с обычными изображениями и текстом; воспроизведение, перемещение, изменение размера и экспорт GIF с сохранением кадров и задержек.
- Повтор чтения после временного сбоя, автоматическое восстановление связи и единая обработка облачных операций. Запросы сохранения автоматически не повторяются.
- Различимые причины ошибок: доступ к закрытому сервису, DNS, HTTPS, таймаут, ответ сервера. Статус и время проверки остаются в окне аккаунта.
- Ограничено время получения ответа целиком, включая тело; сетевое соединение не переиспользуется после смены маршрута VPN.
- Ограниченный журнал диагностики без токенов, паролей, адресов проектов и содержимого файлов.
- Отдельный EXE для удаления приложения и, по выбору, локальных настроек и данных входа. Сохранённые изображения, проекты, исходники и облачные данные сохраняются.

Проверка на ПК подтвердила доступ к аккаунту и облачным проектам. Плавающий сбой предыдущей версии не воспроизвёлся; его точная причина пока не подтверждена.
