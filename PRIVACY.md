# Обработка данных Pixel Studio

Pixel Studio 0.2.1 — самостоятельный редактор. Локальные изображения и проекты остаются на ПК, пока пользователь сам не нажмёт сохранение в облако. Обновление приложения не загружает проекты на GitHub.

## Google-вход

Вход открывается в системном браузере на странице Google. Запрашиваются только `openid`, `email`, `profile`: постоянный идентификатор аккаунта, подтверждённая почта и имя. Пароль приложение не получает. Доступ к Gmail, Google Drive, контактам и управлению Google-аккаунтом не запрашивается.

Сервер использует код входа, PKCE и Google ID token для проверки личности. Google access/refresh/ID tokens не сохраняются в базе проекта. После проверки создаётся отдельный 30-дневный сеанс Pixel Studio: база хранит хеш случайного токена, Google ID, почту, имя и срок действия. На ПК cookie сеанса шифруется Windows DPAPI для текущего пользователя. Выход отзывает этот сеанс; удаление приложения может убрать данные входа с ПК.

## Облачные проекты

Метаданные хранятся в Cloudflare D1, содержимое — в R2. Сохраняются имя, размеры, слои, кадры GIF и время изменения. Каждая операция требует действующего сеанса и проверяет владельца. Другие пользователи приложения не получают доступ к этим проектам. Администратор хостинга технически управляет базой и хранилищем.

Удаление облачного проекта удаляет его запись и содержимое из рабочего хранилища. Удаление EXE само по себе не удаляет облачные проекты. Для удаления своих проектов используйте «Мои проекты». Данные локальных файлов удаляются пользователем средствами Windows.

## Сетевые сервисы и диагностика

Google обрабатывает вход; Cloudflare — запросы и облачное хранение; GitHub — проверку и загрузку обновлений. Эти сервисы получают сетевые данные запроса, включая IP, и применяют свои правила обработки данных. Клиент не передаёт cookie Pixel Studio или Google-токены в GitHub. Проверочная сумма обновления берётся из HTTPS-ответа GitHub; это проверка целостности пакета, а не цифровая подпись издателя Windows.

Локальный connection.log содержит время, обобщённый маршрут, HTTP-статус и код результата. Пароли, токены, ID проектов и содержимое изображений в него не записываются. Журнал ограничен по размеру. В исходниках и публикуемых архивах нет служебных ключей и сеансов пользователя.

По вопросам приложения: https://github.com/Over1inex/pixel-studio/issues . Не публикуйте в issue токены, личные изображения или приватные проекты.
